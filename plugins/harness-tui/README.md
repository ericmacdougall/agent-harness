# Harness TUI

Open a local Go TUI with a private reference to the current conversation from
Codex, ChatGPT desktop, Claude Code or Claude Desktop. A Chromium toolbar action
also captures the rendered messages in the active ChatGPT or Claude browser tab.
Context is inert reference text: this feature does not submit jobs, send messages
or start a backend. Install and configure a compatible local Go executable first.

See the repository's [setup and operating guide](https://github.com/ericmacdougall/agent-harness/blob/main/docs/tui-plugin.md) for
the separate installer, client activation, browser setup, limits and recovery.
The installed plugin uses absolute interpreter/server paths generated by that
installer. Plugin source manifests also support development from a plugin root.

The `open-tui` skill calls the packaged `open_tui` tool with visible context or a
selected excerpt. It never reads hidden client history. Browser snapshots are
rendered excerpts, and long excerpts can be explicitly clipped. References stay
in private local files until you remove them. Review sensitive content before
capturing it; defensive secret filtering does not guarantee complete redaction.

`LAUNCH_REQUESTED` confirms only that Terminal accepted a request. Actual UI
readiness is established by inspecting the new TUI window. An `UNKNOWN` outcome
needs inspection before another attempt.
