fix(desktop): fail closed when a revoked document cannot be replaced

Why: final delta red-team BLOCK on PR 1309 at 7f6c7787 (F1 high, F2 medium): a page whose beforeunload busy-loops 6 s defeats both bounded replacement steps. On the narrowing path the visible tab stayed under agent control with revocation=failed, an agent click still landed and the staged 4 KB file was POSTed after uploads were revoked; on media-drop paths the camera stayed live on the open tab.
What: any revocation or replacement failure (both steps failed, or an internal error) now calls failClosed(): forcefullyCrashRenderer() and close the tab with reason revoke_failed, on every surface; the person loses that tab. The revoke_failed log (reason, tab id, Chromium code) is kept. Agent page commands refuse with revocation_pending while a revocation is pending or failed. The failure text shows whoever controls the tab. F3 is documented on stopTab(). Adds real-Electron busy-beforeunload cases (narrowing visible tab with a staged file and agent clicks; media drop via stopTab and renew) and unit tests for fail-closed, the command refusal, the internal-error path and stop() before about:blank on the revocation path itself.
Testing: `cd apps/desktop && pnpm run build && xvfb-run -a npx vitest run src/agent-browser/revocation-capture.test.ts src/agent-browser/reload-post.test.ts` -> 10 passed (the 3 new busy cases fail on 7f6c7787: two 4277-byte POSTs reached the server and both clicks returned ok; camera heartbeat live 9.9 s with the tab kept); `npx vitest run src/agent-browser/host.test.ts` -> 257 passed (7 new fail on the 7f6c7787 host.ts); `npx vitest run src/agent-browser src/ctl` -> 637 passed, 13 failed (pre-existing files.test.ts x11, capture-return-recovery x2), 10 skipped without a display; `npx tsc --noEmit` clean.
Refs: GoodQA #15477
Risk: a hostile or hung page now loses its tab on revocation; forcefullyCrashRenderer also ends any other tab sharing that renderer process (same-site tabs), which then close as renderer_gone. F3 (disclosed, unchanged): stopTab() on a person-controlled visible tab replaces the document, so typed unsent data is lost and beforeunload protection is bypassed.
