## Outcome

The intelligence worker on self-host production receives GITHUB_APP_PRIVATE_KEY without any person or agent copying, typing or reformatting the key. A root-run host script derives a group-readable, root-owned file from the existing /etc/goodqa/api.env on every deploy. The job dispatcher reads that file when it launches an intelligence job. Every job's env, not only this key, reaches docker through a private env-file instead of the command line. No process argv, log, error body, job row, record or command output ever contains a job secret. intelligence-worker stays held until this is live and the other missing keys are set.
