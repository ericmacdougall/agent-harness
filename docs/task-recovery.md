# Explicit native task recovery

Enroll one authorized task in a private directory before starting its user service. The immutable manifest binds a private prompt, fixed native-agent argv, absolute cwd, read-only completion verifier argv, and bounded attempt/time limits. A fresh invocation must reconcile existing work and uncertain external writes. A zero native process exit never establishes completion.

The manifest has exactly these keys. Use schema native-recovery-v1, task_id with lowercase letters, digits or hyphens (at most 48), cwd as an existing absolute directory, agent_argv beginning with an absolute native codex or claude executable, prompt_file as an owned private absolute file, prompt_sha256, verify_argv beginning with an absolute executable, max_attempts from 1 to 4, attempt_timeout from 1 to 21600 seconds, and task_timeout from 1 to 86400 seconds. A Codex argv can end with exec, --sandbox, workspace-write, and -. The helper supplies the prompt via stdin. No command or prompt may contain secrets.

Use task_recovery.py enroll --task-dir ABS --manifest ABS. The task parent must exist. Enrollment refuses changed declarations. Run with run --task-dir ABS and inspect status --task-dir ABS. Completion is checked before and after native invocation. Status complete means the enrolled verifier exited zero. attempts_exhausted and deadline_exhausted are terminal limits requiring inspection, and exit zero prevents service restart loops.

Generate service files with service --task-dir ABS --kind launchd or --kind systemd. Install launchd output in the user's LaunchAgents directory and bootstrap with launchctl. Install systemd output in the user's systemd directory and enable with systemctl. The generated helper and Python paths must remain available. Login and unsuccessful supervisor exits wake the service. The helper cannot replenish a provider account limit.

A private persistent task lock is held by the supervisor and its dedicated attempt wrapper. The native CLI inherits no lock descriptor. If the supervisor dies, the wrapper keeps ownership until the bounded invocation ends and its receipt is durable. A restarted supervisor returns busy until then. If an interrupted wrapper leaves no terminal receipt, recovery_uncertain preserves the attempt for manual reconciliation because an old native writer may survive. The service stops there. A native invocation killed by signal or timeout while its wrapper remains has a receipt and can be followed by a fresh reconciling invocation. Completion verification suppresses another invocation after orphaned work has completed.

Run pause --task-dir ABS before stopping the service to record an explicit operator pause. It prevents future dispatch and preserves in-flight work for inspection. A new enrollment in a new directory requires new authorization after a pause or exhaustion. This helper is separate from the disabled Codex bridge.

Private current-user files, native executables, verifier, checkout and prompt are trusted enrollment inputs. Hashes bind bytes rather than authenticate user consent. The verifier must be read-only and tied to source, task identity, and independently observed external receipts. Recovery instructions guide the native agent and do not mechanically prove arbitrary writes are idempotent. Keep credentials scoped and completion independently observable.
